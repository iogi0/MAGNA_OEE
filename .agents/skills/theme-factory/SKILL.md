# Theme Factory Skill

This skill provides a curated collection of professional font, color, and design token themes.

## Purpose

To apply consistent, high-contrast, production-grade styling to dashboards, web applications, and analytics artifacts. Each theme includes:
- Cohesive color palette with hex codes
- High-contrast text colors for dark and light backgrounds
- Complementary font pairings for headers and data labels
- Semantic color mappings (Status, Alerts, KPI thresholds)

## Industrial Themes Available

1. **Magna Industrial Dark** (Default for Manufacturing Dashboards)
   - Background: `#0E1117` / `#161922`
   - Card Background: `#1E222D` with subtle `#2E3440` borders
   - Accent Primary: `#E53935` (Magna Red)
   - Status OK: `#4CAF50` (Emerald Green)
   - Status Warning/Downtime: `#F59E0B` (Industrial Amber)
   - Status Critical/Scrap: `#EF5350` (Crimson)
   - Text Primary: `#FFFFFF`
   - Text Secondary: `#94A3B8` / `#CBD5E1`

2. **Clean Enterprise Slate**
   - Background: `#0F172A`
   - Card Background: `#1E293B`
   - Accent: `#38BDF8` (Sky Blue)
   - Text: `#F8FAFC`

3. **High-Contrast Precision**
   - Background: `#000000`
   - Card Background: `#121212`
   - Borders: 1px solid `#333333`
   - Text: `#FFFFFF`
   - Indicators: Pure Red `#FF3333`, Pure Green `#00CC66`, Pure Amber `#FFBB00`
